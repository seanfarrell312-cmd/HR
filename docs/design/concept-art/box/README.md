# Day 3 box reference

Reference images from the designer for Day 3's relic box (D3-04): a plain
dark-wood box with bowed ends.

- `box-front.webp` — the front, with a brass latch.
- `box-back.webp` — the back, plain.

The designer asked for the latch to be left off (2026-11-27), so the box
in the game is plain on every side, like `box-back.webp`.

The in-game model is `boxModel()` in `src/world/storyProps.ts`.
